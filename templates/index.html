PROJECT OVERVIEW

From traffic features to a clear result

The project combines preprocessing with two saved XGBoost models to make a prediction from one network traffic record.

01

Two-stage detection

A binary model first separates normal traffic from suspected attacks. A second model assigns a category to detected attacks.

02

17 selected features

Analyze a focused mix of 14 numerical measurements and 3 categorical fields: protocol, service, and connection state.

03

Readable predictions

Preprocessing prepares the form values for the models, and the result page presents the binary decision and predicted category.
