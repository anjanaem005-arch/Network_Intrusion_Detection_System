DATASET & PROJECT

What the model
looks at.

The attack labels bundled with this project align with UNSW-NB15, a labeled network intrusion dataset covering normal traffic and multiple attack families. This detector evaluates one traffic record using a selected set of connection and packet measurements from its saved preprocessing pipeline.

THE PROJECT

Two steps from record to prediction

Numerical values are scaled and categorical values are encoded using the saved preprocessing objects. The binary XGBoost classifier first predicts normal or attack traffic. If an attack is detected, the multiclass classifier predicts its category.

Traffic record→ Preprocessing→ Binary model→ Attack class

LABELS IN THE MODEL

Prediction classes

The saved label encoder contains these classes. The binary classifier decides whether traffic is normal or an attack; the multiclass model supplies a category for detected attacks.
